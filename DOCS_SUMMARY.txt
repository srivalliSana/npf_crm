💡 KEY TAKEAWAYS
═══════════════════════════════════════════════════════════════════════════════

WHAT IS CCRM?
  A complete, production-ready Customer Relationship Management system for
  educational institution admissions. Manages 200,000+ leads with:
  
  ✓ Multi-channel lead import (7+ sources)
  ✓ Complete application & payment workflow
  ✓ Real-time analytics & reporting
  ✓ Automated daily email reports (3:00 AM IST)
  ✓ Automated S3 backups (3:00 AM IST)
  ✓ Role-based access control (Admin, Manager, Counselor)
  ✓ 99.5% uptime SLA

TECH STACK:
  Frontend: React 18 + Vite + TailwindCSS
  Backend:  Node.js + Express + PostgreSQL
  Backup:   AWS S3
  Email:    Nodemailer (Gmail/SMTP)
  Payments: Razorpay, PayU

HOW TO DEPLOY:
  Option 1 (Easiest): bash DEPLOY.sh
  Option 2 (Manual):  git pull + npm install + npm run build + systemctl restart
  Option 3 (Manual):  Copy files manually

POST-DEPLOYMENT:
  1. Settings → Integrations → AWS S3 Backup (fill credentials)
  2. Settings → Integrations → Daily Email Reports (fill recipients)
  3. Test: POST /api/admin/test-daily-report
  4. Monitor: sudo journalctl -u ccrm-backend -f

DAILY AUTOMATED TASKS (3:00 AM IST):
  1. Email productivity report to configured recipients
  2. Backup database to S3
  3. Backup uploads/ to S3
  4. Backup logs to S3
